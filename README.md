## 🌟 Öne Çıkan Özellikler

| ✨ Özellik | 📝 Açıklama |
| :--- | :--- |
| **Mürekkep & Kağıt Estetiği** 📖 | Yapay parlaklıklardan uzak, gözü yormayan editoryal tipografi, zarif sınırlar ve 5 zengin Zen renk paleti. |
| **Hafıza Sohbeti (Gemini 2.5 Flash)** 🧠 | Geçmiş anılarınızı anlayan ve hatırlayan yapay zeka ile akıcı, empatik Türkçe sohbet. |
| **Sesli Anı Kaydı** 🎙️ | Anılarınıza ses kaydı ekleyin ve dahili oyuncu ile dilediğiniz zaman dinleyin. |
| **Anı Haritası & GPS** 🗺️ | Anılarınızın kaydedildiği coğrafi konumları OpenStreetMap üzerinde pinler halinde keşfedin. |
| **Biyometrik Güvenlik** 🔒 | Parmak izi / Yüz tanıma (FaceID) desteği ile günlüğünüzü meraklı gözlerden koruyun. |
| **Hafıza Bahçem** 🌿 | Yazdığınız her anı ile büyüyen ve zihinsel rahatlama sağlayan dijital zen bahçesi. |
| **AI Duygu Analizi & Günün Sorusu** 🔬 | Metninizden ruh halini otomatik tespit eder ve yazmakta zorlandığınızda ilham verici sorular sorar. |
| **Tam Gizlilik & Çevrimdışı Depolama** 🛡️ | Tüm verileriniz **Hive** veritabanı ile sadece kendi cihazınızda saklanır. |
| **Tek Tıkla Sıfırlama** 🧹 | Ayarlar ekranından tüm anıları tek tıkla temizleyip uygulamayı sıfırdan başlatabilme. |

## 🛠️ Hızlı Çalıştırma & Geliştirme

```bash
# Repoyu klonlayın
git clone https://github.com/mehmeteminyilmaz/gunce.git

# Proje dizinine girin
cd gunce

# Bağımlılıkları yükleyin
flutter pub get

# Web veya mobil cihazda çalıştırın
flutter run
```

## 🏗️ Teknolojik Altyapı

> 🧠 **Yapay Zeka:** `Gemini 2.5 Flash API` — Hafıza sohbeti, ruh hali analizi, günün sorusu  
> 🎨 **Tasarım Mimarisi:** `Editorial Zen Design System`, `Google Fonts (Newsreader & Outfit)`  
> 💿 **Veritabanı:** `Hive (NoSQL)` — Yüksek hızlı, şifrelenebilir yerel depolama  
> 🗺️ **Harita & Konum:** `Flutter Map`, `Geolocator`, `OpenStreetMap`  
> 🎙️ **Ses Servisi:** `Record`, `AudioPlayers`
